Rules being demonstrated

  1. One tab per file. Open it where it lives → focus. Open it in the other pane → it moves (watch the flash).
  2. Open creates, Send targets. Tab menu items change with split state.
  3. No "Open in new pane" on a pane's only tab — nothing to split away from.
  4. Focus follows intent. Blue ring = focused pane (only visible while split).
  5. Close a pane's last tab → split collapses. No unsplit button.
  6. No pane chrome until you split. Headers appear only in split mode.
  7. Drag anything into a pane. Nodes and tabs drag; panes highlight; the right-edge zone previews "open in new pane". Same guard: a pane's only tab can't split away.
